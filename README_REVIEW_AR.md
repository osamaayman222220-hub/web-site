# CareNest — ملاحظات النسخة بعد الفحص

ابدأ بقراءة `AUDIT_REPORT_AR.md` لمعرفة الإصلاحات المنفذة والاختبارات والمهام التي تتطلب إعدادات Supabase أو موافقة منفصلة.

## تشغيل محلي
شغّل الموقع من خادم محلي ثابت، ولا تفتح صفحات HTML مباشرة عبر `file://` لأن تسجيل الدخول وطلبات Supabase تحتاج origin صالحاً.

## رابط الموقع المضبوط حالياً
`https://osamaayman222220-hub.github.io/web-site`

عند شراء نطاق رسمي أو تغيير الاستضافة، حدّث `siteUrl` في `js/config.js`، وقوائم CORS في Edge Functions، وSite URL/Redirect URLs في Supabase Auth.

## قاعدة البيانات
لم يتم تشغيل أو تعديل أي SQL في قاعدة البيانات. راجع تقرير الفحص قبل أي migration، وخذ نسخة احتياطية واختبر على staging أولاً.
